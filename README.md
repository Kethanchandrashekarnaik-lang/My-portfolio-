## 📌 Overview

Welcome to the official portfolio repository for **Kethan C**, a passionate **Software Developer** and Computer Science graduate from **Don Bosco Degree College**. 

This web application goes beyond a conventional static resume by introducing **interactive, OS-themed user interfaces** (iPad OS Split-Screen Profile, PlayStation 5 Project Library Console, Windows 11 Outlook Mail Contact Center, and Terminal Heatmap Dashboard). It delivers an immersive, ultra-responsive experience powered by modern web technologies, fluid CSS animations, glassmorphism design tokens, and clean modular JavaScript.

- **Split-Screen Dashboard**: Interactive tablet OS interface featuring a left navigation dock and multi-pane content display.

- **Interactive Game Tile Carousel**: Browse featured software projects with PS5 DualSense console button prompts (`✖ PLAY`, `🔲 VIEW PDF`, `🔺 SOURCE CODE`).

- **Desktop Window Mockup**: Styled like Microsoft Outlook Windows 11 app with a split sidebar (Compose, Contact Directory, Location Pin, Social Links).
- **Direct Mail & Social Links**: One-click direct phone, email (`chandrashekarnaikkethan@gmail.com`), location, and GitHub integration.

### 📊 5. Developer Activity Dashboard
- **GitHub Terminal Heatmap**: Embedded terminal dashboard displaying real-time commit activity, streak counters, and public project stats for `@Kethanchandrashekarnaik-lang`.

### 🎓 6. Verified Certificate & Credentials Gallery

## 🚀 Getting Started

To run and preview this portfolio locally on your machine:

### Prerequisites
- Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
- *(Optional)* VS Code with the **Live Server** extension for live reloading.

### Local Installation Steps

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Kethanchandrashekarnaik-lang/My-portfolio-.git
   cd My-portfolio-
   ```

2. **Launch with VS Code Live Server**
   - Open the project folder in VS Code:
     ```bash
     code .
     ```
   - Right-click `index.html` and select **Open with Live Server**.

3. **Or Open Directly in Browser**
   - Double-click `index.html` or open it via file browser.
