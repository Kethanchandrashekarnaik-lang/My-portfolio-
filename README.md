# 🚀 Kethan C - Premium Interactive Portfolio

![Portfolio Preview](assets/images/preview.png) *(Note: You can add a screenshot of your site here and name it preview.png)*

Welcome to the repository for my premium personal portfolio website. This project is a highly interactive, beautifully designed web application built to showcase my skills, projects, and professional journey. It leverages modern UI/UX principles, including glassmorphism, micro-animations, and dynamic interface components.

## ✨ Key Features

- **Dynamic Island Navigation:** A responsive, Apple-inspired dynamic island header for seamless navigation.
- **PS5-Style Project Dashboard:** An interactive, game-console-inspired UI to showcase my recent projects with smooth transitions and category highlights.
- **OS-Themed Contact Sections:** Features both Windows 11 and macOS styled interactive elements (including taskbars, docks, and window interactions).
- **Advanced Animations:** Includes typewriter effects, scroll reveal animations, and interactive 3D elements powered by Spline.
- **Particle & Glow Backgrounds:** Dynamic, flowing particle canvas and gradient glows for a premium aesthetic.
- **Dark & Light Mode:** Fully responsive theme switching that adapts to user preference.

## 🛠️ Technologies Used

- **HTML5:** Semantic and accessible markup.
- **CSS3 (Vanilla):** Custom design system utilizing CSS variables, Flexbox/Grid, and modern glassmorphism techniques.
- **JavaScript (Vanilla):** DOM manipulation, interactive handlers (PS5/OS themes), and performance-optimized scroll observers.
- **Spline 3D:** Interactive 3D web elements.
- **FontAwesome:** For rich iconography.

## 🚀 Getting Started

To run this project locally, simply clone the repository and spin up a local server.

### Prerequisites

You'll need a basic local web server to run the project (to avoid CORS issues with module imports). You can use Python, Node, or any simple HTTP server.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. **Run a local server**
   
   *Using Python:*
   ```bash
   python -m http.server 8000
   ```
   
   *Using Node (http-server):*
   ```bash
   npx http-server -p 8000
   ```

3. **Open in Browser**
   Navigate to `http://localhost:8000` to view the portfolio.

## 🎨 Design System

This project uses a custom-built design system located in `assets/css/style.css`. It heavily utilizes CSS variables for rapid theme configuration and maintaining consistency across UI components.
