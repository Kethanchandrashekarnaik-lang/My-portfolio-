## 📌 Executive Summary

Welcome to the official repository of **Kethan C's Personal Developer Portfolio**. This application is an interactive web platform designed with futuristic, OS-inspired user interface paradigms (iPadOS, PlayStation 5 Console Dashboard, and Windows 11 Desktop Suite).

It highlights software projects across **Web Development**, **Machine Learning / NLP**, **Database Management Systems (DBMS)**, and **Cyber Security**, alongside verified academic certifications and interactive background widgets.

---

## ✨ Key Features & OS Design Themes

### 1. 🏝️ Dynamic Island Navigation Header
- **Floating Pill Header**: Dynamic menu bar inspired by modern mobile OS top-bars with interactive active-pill animations.
- **Theme Switcher**: Smooth toggle between Light and Dark visual modes with preserved CSS variable palettes.

### 2. 📱 iPadOS Split-Screen Profile Interface
- **Developer ID Pass**: Realistic digital pass displaying legal info, age, location, and specialization metrics.
- **Tabbed Experience**: Interactive side menu to switch between *Personal Details*, *Communication Directory*, *Academic Record*, and *Technical Skill Matrix*.
- **Skill Progress Indicators**: Animated percentage meters for Python & AI, Web Stack, DBMS/SQL, and Cyber Security.

### 3. 🎮 PlayStation 5 (PS5) Interactive Project Console
- **Carousel Game Selector**: Interactive tile navigation with custom thumbnail glows and sound-effect-ready transitions.
- **DualSense Control Button Prompts**:
  - `✖ PLAY PROJECT`: Launch live interactive web demos.
  - `🔲 VIEW PDF`: Access full project documentation and research papers.
  - `🔺 SOURCE CODE`: Navigate directly to GitHub repositories.

### 4. 💻 Windows 11 Outlook Mail & Communications Suite
- **Interactive Email Dispatcher**: Integrated with **EmailJS SDK** for instant message submission without backend page reloads.
- **Microsoft Edge Social Web Hub**: Modern Edge-inspired browser view showcasing GitHub, LinkedIn, and Instagram connect cards.
- **Windows Maps Location Pin**: Quick location viewer configured for Chitradurga, Karnataka, India.

### 5. 🖥️ GitHub Activity & Terminal Heatmap
- **Real-Time Heatmap**: Displays GitHub commit contributions powered by `ghchart`.
- **Live Activity Badges**: Displays metrics like yearly commits, current streak, public repositories, and community stars.

### 6. 📜 Glassmorphism Certificate Modal Viewer
- **Interactive Lightbox**: Clickable certificate cards supporting high-resolution image previews and embedded PDF document viewers.

## ⚙️ Local Development & Setup

To run this portfolio locally on your computer:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Kethanchandrashekarnaik-lang/My-portfolio-.git
   cd My-portfolio-
   ```

2. **Launch with Local Web Server**:
   - **VS Code**: Install the `Live Server` extension, right-click `index.html`, and select **Open with Live Server**.
   - **Python**:
     ```bash
     python -m http.server 8000
     ```
     Then open `http://localhost:8000` in your web browser.

3. **Configure EmailJS (Optional)**:
   - Open `index.html` and update the EmailJS public key at the bottom:
     ```javascript
     emailjs.init("YOUR_PUBLIC_KEY");
     ```
   - In `assets/js/main.js`, update your Service ID and Template ID:
     ```javascript
     emailjs.send("YOUR_SERVICE_ID", "YOUR_TEMPLATE_ID", templateParams)
     ```
