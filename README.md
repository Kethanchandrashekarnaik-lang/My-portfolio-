# Kethan C | Software Developer Portfolio

Welcome to the repository for my personal developer portfolio! This website serves as an interactive showcase of my software engineering projects, skills, and professional experience.

## 🚀 Overview

This portfolio is a dynamic, highly responsive web application designed to highlight my expertise in building secure web systems, algorithm optimization, and data-driven artificial intelligence solutions. It features a modern, premium user interface with interactive elements, smooth animations, and a sleek dark/light mode toggle.

## ✨ Key Features

- **Modern "Max Pro" Aesthetic:** A highly polished, glassmorphic UI with dynamic mesh gradients and vibrant futuristic accents.
- **Interactive 3D Elements:** Integrated with Spline 3D Viewer for immersive visual experiences.
- **Dynamic Island Navigation:** A sleek, responsive navigation bar inspired by modern mobile OS designs.
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices.
- **Project Showcases:** Detailed sections highlighting key projects such as the **Blood Donor Finder** and **Fake News Detection** systems.
- **Theme Toggling:** Seamless switching between dark and light modes for optimal viewing comfort.

## 🛠️ Technology Stack

- **Core:** HTML5, CSS3, Vanilla JavaScript
- **Styling:** Custom CSS (Flexbox, CSS Grid, Advanced CSS Animations, Glassmorphism)
- **Icons:** FontAwesome 6
- **3D Graphics:** Spline 3D Viewer
- **Fonts:** Google Fonts (Inter, Outfit, Consolas)

## 💻 Getting Started

To view this portfolio locally, no complex build tools or dependencies are required. 

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Open `index.html` in your favorite web browser or start a local live server:
   ```bash
   python -m http.server 8000
   # or use Live Server in VS Code
   ```
